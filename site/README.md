# memtune interactive demo

Static web page that walks one optimization problem through the stages of the memtune framework and shows the
recommended L-BFGS memory parameter next to measured runs.

This folder is also a valid **Hugging Face static Space** (the front matter above). The data in `data/` is
generated by `python -m memtune demo --build-only` (or `python -m memtune demo`, which also opens the page).

Source, documentation and deployment instructions:
<https://github.com/nishanmudalige/OptimizationParameterTuning> (see `docs/DEMO_ROADMAP.md`).
